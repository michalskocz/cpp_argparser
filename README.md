# cpp_argparser

A lightweight, modern, and easy-to-use command-line argument parser for C++23. It utilizes modern C++ features like `std::span` and lambdas to provide a clean and flexible API for defining and handling CLI options.


## Requirements

- A compiler supporting **C++20** (e.g., Clang, GCC, or MSVC).

## Quick Start

### 1. Create an example program (`example.cpp`)

```cpp
#include "arguments.h"
#include <iostream>

using namespace args;

int main(int argc, char **argv) {
  // Initialize parser with program name, version, and description
  Parser parser{"example", "1.0.0", "Example argument parsing program"};

  int count = 0;

  // Define an argument with a long name, short name, description, and a lambda validator
  Argument arg1{"count", 'c', "count provided parameters",
    [&count](span<const string> elements) -> bool {
      count += elements.size();
      return true;
  }};

  // Add argument to the parser
  parser += &arg1;

  // Parse command line arguments
  if (parser.parse(argc, argv) != ParserError::OK) {
    return 1;
  }

  std::cout << count << std::endl;
  return 0;
}
```

### 2. Compile

Compile the program using a C++23 compatible compiler:

```bash
clang++ example.cpp arguments.cpp -std=c++23 -o example_app
```

### 3. Run

```bash
# Display help menu automatically generated by the parser
$ ./example_app -h
example v1.0.0
Example argument parsing program

Usage: example [options]
Options:
    -h, --help      prints this message
    -v, --version       prints version
    -c, --count     count provided parameters

# Check the version
$ ./example_app -v
v1.0.0

# Run with custom arguments (the lambda captures the 3 trailing elements)
$ ./example_app -c a v c
3

# Run without arguments
$ ./example_app
0
```

## API Overview

### `args::Parser`
The main class responsible for parsing `argc` and `argv`.
- `Parser(name, version, description)`: Constructor to set up the basic program info.
- `parse(argc, argv)`: Parses the provided arguments and triggers the corresponding validators. Returns a `ParserError` enum.
- `operator+=` or `add()`: Used to attach `Argument` objects to the parser.

### `args::Argument`
Represents a single command-line flag.
- `Argument(longName, shortName, description, validator)`:
  - `longName`: Used with `--` (e.g., `count` becomes `--count`).
  - `shortName`: Used with `-` (e.g., `c` becomes `-c`). Set to `IGNORE_SHORT` (`'\0'`) if you only want a long name.
  - `validator`: A `std::function<bool(std::span<const std::string> elements)>`. It receives all positional arguments that follow the flag. Returning `false` triggers a validation error and prints the help message.
